# Lista de Compras

Uma aplicação front-end para organizar uma lista de compras por categorias, com visual limpo e interface simples.

## 🛒 Sobre o projeto

Este projeto foi desenvolvido como exercício de HTML e CSS, com foco em:

- estrutura de página responsiva;
- organização visual de categorias de compra;
- criação de uma interface amigável para adicionar itens;
- prática de design moderno e elegante.

## ✨ Funcionalidades

- Cabeçalho com logo e identidade visual personalizada;
- Seção de categorias como Hortifrute, Carnes, Bebidas e Material de limpeza;
- Campos para adicionar itens à lista;
- Layout centralizado e visual limpo.

## 🧰 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
